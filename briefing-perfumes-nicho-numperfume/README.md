# NUM Perfume — Briefing Ejecutivo

Sitio de documentación con la estrategia de crecimiento orgánico para NUM Perfume.

## Estructura

```
src/
├── layouts/DocsLayout.astro    ← Layout documentación con sidebar
└── pages/
    ├── index.astro             ← Resumen ejecutivo
    ├── mercado/index.astro     ← Estudio de mercado
    ├── prd/index.astro         ← PRD mejoras técnicas
    ├── seo/index.astro         ← Plan SEO
    ├── ventas/index.astro      ← Estrategia de ventas
    ├── roadmap/index.astro     ← Roadmap 90 días
    ├── jarvis/index.astro      ← Arquitectura NUM Jarvis (AI)
    └── herramientas/index.astro
```

## Ejecutar

```bash
bun install
bun run dev      # → http://localhost:4321/
bun run build    # → dist/
```
